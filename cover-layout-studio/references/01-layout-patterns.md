FONT = "C:/Windows/Fonts/NotoSansSC-VF.ttf"
def bold(size):
    f = ImageFont.truetype(FONT, size)
    try: f.set_variation_by_axes([700])
    except Exception: pass
    return f

## 版式 A：抖音 3:4 杂志卡（1080×1440）

- 底：(247,243,236) 米白
- 主标题 118~128pt 居中 y≈90；副标题 60pt 灰 (120,116,108) y≈285
- 照片卡：图宽 980 → 白卡 padding 18、圆角 22~30、偏移投影 (0,6)+Blur(16)
- 卡位置：去掉底部元素后下移至 y≈520 视觉居中（勿顶到标题）
- 关键经验：底部加第三层文字/圆点易被用户圈删；留白即设计

## 版式 B：小红书 4:3 全幅出血（1440×1080）

- 关键帧 4:3 裁剪：先算 tw=h×4/3，x0 偏移保住主体与关键装置（如红绿灯）都在画内
- 主标题 96~108pt 左上 (70,60)，深色 (38,52,71) + 米白 stroke 6px + 柔和投影
- 副标题 62pt 紧随其下；文字尽量落在干净墙区，避开产品海报正面
- 底部元素（品牌条/CTA）用白色 pill 底 (255,255,255,225) 圆角 40+

## 微信搜索框 CTA（片尾卡同款）

- 结构：上方 "微信搜索" 小字 46pt 灰 → 白色圆角长条（宽 1150 高 150，半径=高/2，浅灰描边 3px + 投影）
- 条内：左侧放大镜（圆环 outline 10px + 45° 手柄线）、78pt 深色文字、右侧微信绿 (7,193,96) 胶囊"搜索"按钮 50pt 白字
- 文字垂直居中用 `cy - th//2 - bb[1]` 修正字形顶部空隙
