# 去水印与常见缺陷修复 Playbook

## 1. 右下角 AI 水印：PIL 局部克隆法（唯一推荐）

**禁止生成式 erase**——会重绘区域并毁掉产品包装文字/纹理细节。

两种策略：
- **clone（克隆）**：从水印左侧/上方取同纹理干净块平移覆盖（地面、墙面等连续纹理适用）
- **stretch（拉伸）**：取水印左侧一条窄带横向拉伸覆盖（渐变墙面适用）

要点：
- 采样源必须是不含主体/文字的干净区；若主体压到右下角 → 重抽（prompt 加"右下角留大片干净地面"），不要硬修
- 覆盖后边缘 GaussianBlur(2~4) 羽化，检查接缝

## 2. 出图穿模/拼接错误

症状：产品包装文字乱码、狗腿数量错误、手指粘连。
处置：局部无法修 → 整图重抽，prompt 增加对应负面约束；包装文字类必须重抽（克隆修不了文字）。

## 3. 视频阶段的画面缺陷（回溯到静帧思维）

| 缺陷 | 根因 | 修复 |
|---|---|---|
| 红绿灯三灯全亮 | I2VA 模型脑补"灯就该亮" | 重抽无效时：取首帧熄灭灯透镜 → ffmpeg 静态 overlay 打补丁（仅固定镜头适用） |
| 投影漂移/变形 | 提示词没锁死 | I2VA prompt 加 "remains perfectly still, static poster" |
| 主体比例回缩 | 模型物理先验 | 首帧 prompt 强化倍数描述 + 缩短时长 |

## 4. 验收清单（每张定稿前）

- [ ] 人物与角色板一致（发型/logo/服装）
- [ ] 产品包装文字清晰无乱码
- [ ] 比例达到要求的夸张度
- [ ] 视线方向正确
- [ ] 右下角无水印、无残留克隆接缝
- [ ] 投影无光影溢出不挡前景
