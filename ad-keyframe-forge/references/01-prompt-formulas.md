# 角色板 / 关键帧提示词公式

## 1. 角色板提示词（工服参考图 + 描述）

```
[参考图: 工服效果图]
生成一张角色板：年轻女性，穿参考图中的宝蓝色 Polo 工服（金色盾形 logo 保留），
长波浪黑发、有酒窝、深灰长裙、白鞋。
自然皮肤肌理、裸妆、柔和暖光、温馨氛围、纯色背景、全身站姿、正面 3/4 侧面各一。
```

迭代修正词库（按需追加，一次只改一类）：
- 塑料感 → "自然皮肤纹理、毛孔细节、裸妆、无磨皮感"
- 发型 → "波浪蓬松长发、发丝细节"
- 光线 → "柔和暖光、温馨氛围、奶油色背景"

## 2. 关键帧六段锚定法

```
① 总述：一句话场景（如"宠物店内，女孩走向两只巨型边牧"）
② 形象锚定：[参考角色板] 同一位女孩，长波浪黑发、酒窝、宝蓝 Polo 金盾 logo、深灰长裙白鞋
③ 场景装置：红绿灯立于画面右侧（仅绿灯亮）；背景墙为 [参考产品图] 的巨幕平面投影，
   flat poster projection, no light spill, does not occlude foreground subjects
④ 动作姿态：女孩蹲下伸手摸成犬下巴；幼犬站立扑向她膝盖
⑤ 比例尺度：成犬马一样大（约 20 倍真实体型），女孩身高只到成犬背部
⑥ 光线氛围：柔和暖光、温馨、奶油色调、浅景深
负面约束：no watermark, no text artifacts, 右下角留大片干净地面
```

## 3. 双参考图调用要点

- 参考图 1 = 角色板（锁人物）；参考图 2 = 当幕产品 PNG（锁包装）
- input_fidelity 用 high，尺寸与目标视频比例一致（如 1536×1024 对应 3:2）
- 每镜只换"③场景装置 + ④动作姿态"，其余段保持不变 = 全片形象一致

## 4. 视线与构图

- 不看镜头：`looking at the dog, not at the camera`
- 去水印友好构图：`主体居中偏左，右下角留大片干净地面/墙面`
- 巨幕投影不被遮挡检查：出图后确认投影完整可见且前景主体无投影叠加色斑
