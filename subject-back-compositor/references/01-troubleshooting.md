# 分层合成踩坑链与 QC 方法

## 五级踩坑链（按此顺序排查，勿跳级）

| 级别 | 症状 | 根因 | 解法 |
|---|---|---|---|
| L1 | 文字压发丝/边缘生硬 | drawtext 顶层叠加 | 改 rembg 分层（基本法） |
| L2 | 狗白脸/白胸透字 | u2net 把白色毛发误判为背景 | `fill_holes()`：反相蒙版四角 floodfill 标记外部背景，未到达区域并回蒙版 |
| L3 | 喉咙/胸口白毛仍透 | 白毛与浅色墙"连通"，非封闭孔洞，fill_holes 够不到 | 双模型并集：u2net 与 isnet-general-use 误判区域互补，np.maximum 取并集 |
| L4 | 单帧正确但播放时**闪烁** | rembg 逐帧独立推理无时序一致性，歧义区忽对忽错 | **时序平滑**：±W 帧蒙版逐像素 max。W=4 可能仍有残余（正确分类只在个别帧出现，滑窗丢失）；**W=12（±0.5s）根治** |
| L5 | 时序 max 后文字空洞过大 | 快速运动主体拖出大轨迹 | 准静态镜头安全；运动快时减小 W 或接受 L4 级方案 |

关键认知：白毛 vs 米白墙面对所有分割模型都是歧义区，**没有任何单帧方案能 100% 稳定**——时序聚合是唯一出路。只要窗口内任一帧把白毛判为主体，整段都盖住（宁遮勿透）。

## 量化 QC（比肉眼可靠）

```python
# 1) 稳定性指标：叠加色像素数的帧间跳变
#    闪烁版 max 跳变 ~7000+，时序平滑后应 <2000
# 2) 叠加色检测：用特征色掩码而非整帧 diff（二次编码噪声会污染 diff）
red = (R>150) & (G<110) & (B<90) & (R-G>70)   # 按实际叠加色调阈值
# 3) 帧区间归属：叠加层 IoU 匹配模板，区分多段（如 3/2/1 各覆盖哪些帧）
```

## 帧区间检测技巧

- **不要**用整帧 diff（合成版 vs 干净版）——二次编码噪声让每帧都"有差异"
- 用叠加层的**特征色掩码计数**（>阈值视为该帧有叠加），再用模板 IoU 分类是哪一个图形

## 常见误判处置

- 两狗/两人之间的**真实缝隙**透出文字属正确分层（文字本来就在墙上），QC 时对照原帧区分"真缝隙"与"误判透字"
- 修复后全段目检 3 个连续帧条（frame t-1/t/t+1 横拼）比单帧更容易发现闪烁
