# 广告片复刻流水线 · Hermes 总控

## 角色边界

只做编排：识别当前阶段 → 调度对应原子 skill → 验收产物契约 → 决定是否进入下一阶段。
**禁止**在总控里直接写提示词、跑合成、做封面——这些全部下放给原子 skill。

## 流水线阶段图

```
S0 逆向拆解 ──► S1 创意改编 ──► S2 关键帧锻造 ──► S3 批量I2VA ──► S4 分层合成 ──► S5 节奏混音 ──► S6 分发资产
(复用现有skill)  (总控直接做)   (ad-keyframe-forge) (复用现有skill)  (subject-back-     (rhythm-mix-      (cover-layout-
                                                                  compositor)       delivery)        studio)
```

## 阶段调度表

| 阶段 | 调度对象 | 输入契约 | 输出契约（验收标准） | 门控 |
|---|---|---|---|---|
| S0 拆解 | `sph-video-reverse-breakdown` | 参考片链接/文件 | 镜头时间轴（含切点秒数）+ 视觉结构拆解 + 原片BGM音频文件 | 切点时间轴齐全 |
| S1 改编 | 总控直接执行 | S0 结构 + 用户产品/品牌素材 | 多幕映射表 + 一句话剧情 + 角色设定（服装/形象锚定） | ⛔ **用户确认门**：结构映射必须等用户批准 |
| S2 关键帧 | `ad-keyframe-forge` | S1 设定 + 产品图 + 工服/角色参考 | `keyframes/V<n>_<名>_定稿.png` ×N（用户逐帧确认） | ⛔ **用户确认门**：全部定稿后才进 S3 |
| S3 I2VA | `keyframes-batch-video` + `minimax-video` + `h3-prompt-writing` | 定稿关键帧 + 逐镜提示词 | `clip_V<n>.mp4` ×N（按时长脚本） | 逐镜目检：无运动缺陷（灯全亮/投影漂移等） |
| S4 分层合成 | `subject-back-compositor` | 需叠加的大字/图形 + clip | 文字压主体背后的合成 clip | 抽帧 QC：透字/闪烁为零 |
| S5 节奏混音 | `rhythm-mix-delivery` | 全部 clip + S0 切点 + BGM | 成片 mp4（切点对齐参考片、响度对齐） | ⛔ **用户确认门**：成片确认 |
| S6 分发 | `cover-layout-studio` | 关键帧/成片帧 + 文案 | 各平台封面（抖音 3:4、小红书 4:3 等） | 用户截图圈选迭代至定稿 |

## 门控规则

1. **用户确认门（⛔）不可跳过**：S1 结构、S2 定稿、S5 成片三处必须等用户显式说"可以/确认/继续"才推进。
2. **契约不达标→留在本阶段修复**；修复无效→回退上一阶段（如 S3 画面缺陷无法补丁修复→回 S2 重抽关键帧，重抽时 prompt 加预防性表述）。
3. **中间产物强制保留**：每阶段的"干净版"（无叠加层版 clip、蒙版缓存、帧目录）保留到项目交付，局部返工不重跑全链路。
4. **状态记录**：项目目录维护进度（当前阶段、已定稿清单），用户问进度能直接回答；断点续做从最近达标阶段继续。

## 命名与目录约定

- 项目根：`<项目文件夹>/<片名_复刻>/`；子目录 `keyframes/`（关键帧）、`keyburns/`（合成与成片）、`manual-prompts/`（逐镜提示词）
- 迭代版本 `_v1/_v2…`；用户批准的版本改名 `_定稿`；过程产物（抽帧、预览、临时脚本）交付时可清理；项目产出（脚本/成片/封面/关键帧定稿）永不删
- 字体：`C:/Windows/Fonts/NotoSansSC-VF.ttf`（PIL `set_variation_by_axes([700])` 加粗）

## 改编公式（S1 执行要点）

保留参考片**骨架**：结构（几幕/几秒/什么钩子）、节奏切点、运镜逻辑、标志性视觉装置（倒计时、红绿灯、巨幕投影等）。
替换**血肉**：主体（品牌角色）、产品（逐一映射到幕）、文案（品牌 slogans）；BGM 可直接复用原片提取的音频。
映射表先行：一行一幕「幕名 → 产品 → 场景动作 → 装置状态」，交用户确认。
